Appsmith İle Doğrudan Entegrasyon

Projeye özel hazırlanmış Appsmith JSON şablonunu tek tıkla Appsmith Cloud veya yerel Appsmith sunucunuza aktarabilirsiniz.

1. app.appsmith.com adresinde ücretsiz hesap açın veya yerel Docker'ı başlatın.
2. "Create New" → "Import Application" seçin.
3. admin-panel/appsmith/appsmith-app.json dosyasını yükleyin.
Appsmith JSON İndir Appsmith'e Git

ToolJet İle Doğrudan Entegrasyon

ToolJet formatındaki REST API sorguları, CRUD tabloları ve hazır modal arayüzlerini projenize bağlayın.

1. app.tooljet.com adresine gidin.
2. "Import App" butonuna tıklayın.
3. admin-panel/tooljet/tooljet-app.json dosyasını seçin.
ToolJet JSON İndir ToolJet'e Git
